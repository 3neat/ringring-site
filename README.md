# Ring Ring site

The public pages for [Ring Ring](https://ringring.neatneatneat.dev): the home page, the
[Privacy Policy](https://ringring.neatneatneat.dev/privacy/) and
[Support](https://ringring.neatneatneat.dev/support/). Static HTML served by GitHub Pages
with the custom domain in `CNAME`.

The game itself is in a private repository. The policy and support pages are exported from
the game service (`/privacy` and `/support`) so the wording stays the same in both places;
if you edit one, update the other.
